A lightweight Go‑based dynamic‑sampling proxy for LLMs.
Automatically adjusts temperature, top‑k, top‑p, and retry behavior based on request intent (coding, planning, explanation, architecture, etc.).
Improves stability, reduces loops, and avoids the performance penalty of Python‑based proxies like Niro.
Supports llama.cpp and OpenAI‑compatible backends with a built‑in dashboard.
